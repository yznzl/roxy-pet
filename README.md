左右跑步时的手部动作感觉还是差点意思。每次只调整这么一小处，都要花不少 token。等后面有空、token 也充足的时候再继续优化吧。

## 如果想从零开始制作

可以参考下面的最小可复现清单：

1. 安装 `hatch-pet`
2. 准备一张高识别度的角色参考图
3. 创建一次新的 pet run
4. 锁定 canonical base
5. 生成图片的九种状态
6. 合成 `spritesheet.webp`
7. 验证 atlas 合规
8. 将 `pet.json` 和 `spritesheet.webp` 放进 `~/.codex/pets/<pet-id>`
9. 在 **Settings → Appearance → Pets** 中刷新并选择

准备好角色参考图后，就可以按这个流程开始制作。

先给出最终编码资源的逐帧对比和动画预览，再按我的确认或安装指令推进。
